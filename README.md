# PipNex Flow

Mobile-first frontend prototype for PipNex Flow, a free trading-analysis and strategy workspace.

## Run
Open `index.html` in a modern browser, or host this folder as a static site.

## Current features
- Responsive dashboard and mobile navigation
- Sample watchlist and illustrative chart (not live data)
- Chart screenshot preview upload (analysis not connected)
- Strategy notes save/delete in browser local storage
- Simplified position sizing calculator
- Backtesting, MT5, news and settings status pages

## Not connected yet
Live prices, AI chart analysis, backtesting engine, Firebase/auth, MT5/broker execution, economic calendar, push notifications.

This prototype is not a trading signal service. Verify position-size estimates against your broker's specifications.
